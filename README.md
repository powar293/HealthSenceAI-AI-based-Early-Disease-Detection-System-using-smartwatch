\## Overview

This project is an AI-based system that detects early health issues using smartwatch data like heart rate, SpO2, sleep patterns, and activity levels.



\## Features

\- Real-time health monitoring

\- AI-based disease prediction

\- Control Panel (Auto \& Manual Mode)

\- Emergency alert system with 15-second countdown

\- Live location sharing

\- Automatic emergency calls to contacts \& ambulance

\- Health dashboard with graphs and analytics



\## Control Panel

\- Auto Mode: Generates random health data for simulation

\- Manual Mode: Adjust health values to demonstrate detection



\## Emergency Alert System

\- Detects critical health condition

\- Starts 15-second countdown

\- User can press "I am OK" to stop alert

\- If not stopped:

&#x20; - Calls emergency contacts

&#x20; - Sends live location

&#x20; - Alerts ambulance



\## Project Structure

\- frontend/ → React UI

\- backend/ → API \& server

\- ml-model/ → AI prediction logic (optional)
